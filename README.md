# Suma phone app

The iPhone app for Suma Studios: a teammate's questions (the desk phone), the team, and the reports.
Open it from the QR code on the desk phone in Suma, then Share → Add to Home Screen.

There are no secrets in this repo. A phone's calls and answers are end-to-end encrypted with a key
that lives only on that phone and its Suma office.

Published from the Suma app (app/public/phone/). Don't edit here.
